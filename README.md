## Installation

Install With Git Clone

```bash
  git clone -b joki_rafeyfa https://github.com/nabils24/jokian
```

Kemudian masuk kedalam folder jokian->backend

```bash
cd jokian/backend
```
Kemudian lakukan penginstalan libary

```bash
npm run install_bahan
```

selanjutnya lakukan import database 

!Note jangan lupa menambahkan database diphpmyadmin!

untuk setting nama databasenya bisa klik 
[di sini](/backend/config/config.json)

lalu jalankan ini

```bash
npm run import_database
```

kemudian jalankan ini untuk menambahkan data

```bash
npm run import_bahan
```

## Untuk Menjalankan Kode

untuk menjalankan kode ini dalam mode development

```bash
  npm run start
```
